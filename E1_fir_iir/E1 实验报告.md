## 实验要求与分析

### 要求

1. FIR：31 阶（滤波器长度 32），截止频率 2 kHz
2. IIR：8 阶（4 级 2 阶级联），截止频率 2 kHz
3. 通过分析输入/输出信号，比较滤波器的单位脉冲响应、幅频响应、相频、群延迟
4. 通过板采数据验证数据链路正常同时FIR、IIR生效

### 分析

设计阶段用 Matlab 实现，获得 FIR 和 IIR 的参数，然后 IIR 参数转成多级二阶IIR串联以避免数值问题。

之后再example代码的基础上添加自写的FIR和IIR函数和处理流程，然后再加入记录原始数据和处理后数据的代码，让程序处理数据的同时把数据保存在用户栈（user stack）中，测试后将这块存储dump memory出来，再通过matlab进行频谱分析。

## 实验方法和结果

### FIR和IIR的参数获取

用 Matlab 获取，通过设置采样率`fs`和截止频率`fc`以及FIR和IIR的阶数等，利用 `fir1` 、`butter` 函数获得滤波器参数

```matlab
fs = 48000;          % 采样频率
fc = 2000;           % 截止频率
N_fir = 32;          % FIR 长度（31阶）
N_iir = 8;           % IIR 阶数（4级2阶）

% filter design
b_fir = fir1(N_fir-1, fc/(fs/2));            % FIR，31阶
b_fir_test = fir1(N_fir-1, fc/(16000/2));            % FIR，31阶 test fs = 16000Hz
[b_iir, a_iir] = butter(N_iir, fc/(fs/2));   % IIR，8阶
```

> 这里设置 test fs = 16000Hz 是要说明这个如果 fs 设置错误会导致设计结果产生 fs/fs_real 的倍数偏差，见 section 2.2

然后IIR的参数要用`tf2sos`转成四个2阶IIR的参数

```matlab 
[sos, g] = tf2sos(b_iir,a_iir);
```

其中`sos` 是 4x6 的矩阵，每行是 [b0,b1,b2,1,a1,a2]，`g` 是整体增益

### FIR和IIR的频响、单位脉冲响应、相频、群延迟

通过matlab函数`freqz`得到频响并画图

```matlab
% 幅频、相频、群延迟
[H_fir, w] = freqz(b_fir, 1, 1024, fs);
[H_iir, ~] = freqz(b_iir, a_iir, 1024, fs);
[H_fir_test, ~] = freqz(b_fir_test, 1, 1024, fs);

% 群延迟（对相位求导）
gd_fir = -diff(unwrap(angle(H_fir))) / (2*pi*(fs/1024));
gd_iir = -diff(unwrap(angle(H_iir))) / (2*pi*(fs/1024));
```

这里可以看出如果`fs`设置错误，会导致`fc`实际的频率产生`fs/fs_real`的倍数差

% impulse response

for i = 1:4

### 板上采集数据并对比滤波效果

选用频率为 1000,2000,6000Hz 的sin合成波作为测试输入，通过matlab生成音频并保存文件，然后在测试板子的时候在电脑上循环播放这段音频，通过在`adc_dac_playback.c`中设置的采集函数将raw和processed data采集到`int16_t pRawCapture[]`和`int16_t pPCapture[]`这两块存储空间中，待采集结束（设置采集时间0.5s），通过cces的 memory browser的 dump memory 功能将两份数据分别导出（`.dat`文件）。
