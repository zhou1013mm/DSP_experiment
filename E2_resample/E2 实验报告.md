## 理论解释

### 抗混叠滤波

1. 为什么会产生混叠，是什么混叠

   由nyquist采样定律，采样率为48000Hz时，最高能采到24000Hz，更高的频率就会混叠到下一个频率周期中，因此当采样率从48000Hz降低到8000Hz时，原本可以采集到4000Hz~24000Hz的频率分量，现在则采集不到了，但是如果直接每6个点采一个点，那么4000Hz以上的频率成分会按照8000Hz为周期，中心对称地叠加到-4000~4000Hz的范围上
   \[
   x_{new}(n) = x_{old}(6n)
   \\
   F[x_{new}(n)] = H_{new}(j\omega)=\sum_n^{N/6}e^{-j\omega n}x_{new}(n)= \sum_i^{N}e^{-j(\omega/6) n}x_{old}(n) = H_{old}(j\omega/6)
   \]
   所以应该在降采样之前先用3~4000Hz截止频率的低通滤波对信号滤波，之后再降采样，就能防止4000Hz以上分量混叠到降采样后的频谱中

   <img src = assets/ppt1.png >

2. 抗混叠滤波如何抗混叠，怎么设计

   如上所说，就是一个低通滤波，截止频率在大约$f_{s,new}/2=4000Hz$，一般用Kaisser 窗函数法进行设计  

### 抗镜像滤波

   1. 为什么会产生镜像，是什么镜像

      插值升采样的原理就是：将8k采到的信号每个点后插入5个0点，这样总点数变为6倍，那么就相当于升6倍采样。直接这样操作后得到的频谱实际上是
      \[
      x_{new}(n) = \cases{x_{old}(n/6),n=6k\\\\0,其他}
      \\
      F[x_{new}(n)] = H_{new}(j\omega)=\sum_n^{6N}e^{-j\omega n}x_{new}(n)= \sum_i^{N}e^{-j6\omega n}x_{old}(n) = H_{old}(6j\omega)
      \]
      所以相当于把原来的频谱进行一个6倍的频率轴压缩，则本来一个采样频率周期范围内的频谱，现在会重复6次并入一个48k频谱范围，那么显然我们只需要第一个范围也就是-4k~4k的内容

      <img src = assets/ppt2.png >

   2. 抗镜像滤波如何抗镜像，怎么设计

      由上面所说，显然我们只要先给8k信号补零到6倍长度然后对其进行4k截止频率的低通滤波即可，所以也和抗混叠滤波一样，但注意这里的滤波器不需要归一化（或者用一样的filter后整题 x 6）

```matlab
%% ===== 1. FIR 抗混叠低通 (48k -> 8k) =====
fp  = 3000;
fst = 4000;
Ap  = 1;
Ast = 50;

f_vec = [fp, fst];
a_vec = [1, 0];
dev   = [(10^(Ap/20)-1)/(10^(Ap/20)+1), 10^(-Ast/20)];
[n, ~, beta, ~] = kaiserord(f_vec, a_vec, dev, fs_in);
n = n + mod(n, 2);

fc = (fp + fst) / 2;
Wn = fc / (fs_in / 2);
h_dec = fir1(n, Wn, 'low', kaiser(n+1, beta));
h_dec = h_dec / sum(h_dec);       % 直流增益 = 1

L_fir  = length(h_dec);
gd_fir = (L_fir - 1) / 2;
fprintf('FIR: 阶=%d 长=%d 群延迟=%d\n', n, L_fir, round(gd_fir));

%% ===== 2. 上采样 FIR (同形状, 增益 ×P) =====
h_int = h_dec * P;
```

```c
/* 48k -> 8k 抗混叠降采样 */
static inline int downsample_48k_to_8k(const float *x, int n_in, float *y)
{
    int count = 0;
    int i, k;
    for (i = 0; i < n_in; i += DEC_FIR_Q) {
        float acc = 0.0f;
        for (k = 0; k < DEC_FIR_LEN; k++) {
            int idx = i - k;
            if (idx >= 0) acc += dec_fir_coeff[k] * x[idx];
        }
        y[count++] = acc;
    }
    return count;
}
```

```c
/* 8k -> 48k 多相上采样 */
static inline int upsample_8k_to_48k(const float *x, int n_in, float *y)
{
    const int P = INT_FIR_P;
    const int branch_len = (INT_FIR_LEN + P - 1) / P;
    int n, m;
    for (n = 0; n < n_in * P; n++) {
        int phase = n % P;
        int q     = n / P;
        float acc = 0.0f;
        for (m = 0; m < branch_len; m++) {
            int hidx = phase + m * P;
            if (hidx >= INT_FIR_LEN) break;
            int xidx = q - m;
            if (xidx >= 0 && xidx < n_in)
                acc += int_fir_coeff[hidx] * x[xidx];
        }
        y[n] = acc;
    }
    return n_in * P;
}
```

```c
/* 8k 域 IIR 低通 (DF2T, 状态跨调用保持) */
static inline void iir_lpf_8k(const float *x, float *y, int n)
{
    static float z[LPF_IIR_N_SOS][2] = {{0.0f}};
    int i, s;
    for (i = 0; i < n; i++) {
        float in = x[i];
        for (s = 0; s < LPF_IIR_N_SOS; s++) {
            const float *c = lpf_iir_sos[s];
            float out = c[0] * in + z[s][0];
            z[s][0] = c[1] * in - c[4] * out + z[s][1];
            z[s][1] = c[2] * in - c[5] * out;
            in = out;
        }
        y[i] = in * LPF_IIR_GAIN;
    }
}
```
